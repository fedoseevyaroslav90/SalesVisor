Отчёт по срокам — по месяцам первой даты клиента

Первая дата — конец первой декады светофора (обещано клиенту). «В срок» — отгружено не позже неё; «+N декад» — отгружено позже на N декад; «не выполнено» — дата прошла, а позиция не отгружена; «в работе» — дата не наступила. OTD месяца — «в срок» из отгруженных и невыполненных. Отгрузка — по фактическим датам отчёта по отрезкам.

Порядок не важен: строки плана производства и диспетчерского, для которых позиции ещё нет, применятся после загрузки отчёта по отрезкам или светофора.

Забрать из Metabase сейчас

Нужен API-ключ Metabase в настройках сервера.

Как читать светофор

  • смещение от первой требуемой даты 0 дней и меньше
  • смещение 10–30 дней
  • смещение больше 30 дней
  • позиция ещё не переведена в Z4, первой даты нет
  • просрочено текущая декада уже прошла, а позиция не отгружена
