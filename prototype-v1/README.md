# SalesVisor — контроль исполнения заказов покупателей

Веб-приложение для менеджеров и отдела сервиса. Оно сводит в одну таблицу три источника:

1. **Заказы и обещанные даты.** Первая дата, которую пообещали клиенту, запоминается навсегда. Каждый перенос попадает в историю с причиной.
2. **План производства.** Из него берётся плановая дата готовности заказа.
3. **Отчёт по отрезкам.** Из него считается фактическая готовность заказа (факт / план).

По каждому заказу приложение считает запас: сколько дней остаётся между плановой готовностью плюс отгрузкой и обещанной датой. По запасу заказ получает статус:

| Статус | Когда |
|---|---|
| Просрочен | обещанная дата прошла, отгрузки нет |
| Не успеваем | план производства плюс отгрузка позже обещанной даты, или плановая готовность прошла, а по отрезкам заказ не закончен |
| Нет в плане | заказа нет в плане производства |
| Мало запаса | успеваем, но запас меньше порога из настроек |
| В срок | запаса достаточно или заказ уже сделан |

Менеджер выбирает себя в списке «Показать» и видит только свои заказы. Специалист сервиса видит все заказы. В карточке заказа есть история обещанных дат, план, отрезки, комментарий, перенос даты и отметка об отгрузке.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run demo   # по желанию: демо-заказы и примеры файлов в data/demo/
npm start      # http://localhost:3000
```

База хранится в `data/salesvisor.db` (SQLite). Путь можно поменять переменной `SALESVISOR_DB`, порт переменной `PORT`.

## Загрузка данных

На вкладке «Загрузка данных» принимаются `.xlsx` и `.csv` (разделитель `;` или `,`, кодировка UTF-8 или Windows-1251). Колонки ищутся по названиям, строка заголовков может быть не первой. Шаблоны файлов можно скачать там же.

| Файл | Обязательные колонки | Необязательные |
|---|---|---|
| Заказы | Номер заказа | Клиент, Менеджер, Изделие, Количество, Дата заказа, Обещанная дата, Причина переноса |
| План производства | Номер заказа, Окончание | Операция, Начало |
| Отчёт по отрезкам | Номер заказа, Факт | Отрезок, План, Дата |

При повторной загрузке плана или отрезков строки загруженных заказов заменяются целиком. При повторной загрузке заказов обновляются поля, а если изменилась обещанная дата, это записывается как перенос.
