# SalesVisor — контроль исполнения заказов покупателей

Веб-приложение для менеджеров и отдела сервиса. Оно собирает в одном окне:

- **Светофор** (Metabase, вопрос 573): первая требуемая дата клиента («Первая декада»), где заказ сейчас («Текущая декада»), смещение и цвет;
- **Отчёт по отрезкам** (Metabase, вопрос 522): требуемая дата, план отгрузки и этап каждого отрезка (произведён, на складе, готов, в пути, отгружен, отфактурирован), менеджер, номер задачи в Битрикс24.

При каждой загрузке приложение сравнивает свежие данные с прошлыми и записывает в журнал все переносы декад и треб. дат, смену цвета и этапа. Лента «Изменения» показывает, что сдвинулось за день, неделю или месяц.

Описание проекта и связки с Битрикс24: [docs/proekt-v2.md](docs/proekt-v2.md). Первый прототип на Node.js лежит в `prototype-v1/` для истории.

## Экраны

- **Заказы.** Фильтры по менеджеру, отделу и поиску. Плитки: просрочка, красные, жёлтые, зелёные. Выбор «в работе», «хвосты» (срок прошёл больше полугода назад) или «все».
- **Карточка заказа.** Связь с задачей и сделкой Битрикс24: номер из SAP или указанный вручную, при настроенном вебхуке с ответственным и сроком. Позиции со светофором, первой и текущей декадой, треб. датой, планом и этапом. Отрезки открываются по клику. История изменений и комментарии.
- **Изменения.** Все переносы за период, их можно фильтровать по виду.
- **Загрузка.** Ручная загрузка CSV или Excel из Metabase и кнопка «Обновить из Metabase».

## Запуск на сервере

```bash
cp .env.example .env    # заполнить пароль базы, адрес и API-ключ Metabase, вебхук Битрикс24
docker compose up -d    # веб на порту 8000 и синхронизация с Metabase раз в час
```

Секреты (API-ключ Metabase, адрес вебхука Битрикс24) хранятся только в `.env` на сервере. В репозиторий этот файл не попадает.

Если портал ставит авторизацию перед приложением, имя пользователя берётся из заголовка `X-Remote-User`.

## Локальный запуск и тесты

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m salesvisor load отрезки.csv светофор.csv   # по умолчанию база SQLite в data/
python -m salesvisor serve --port 8000
python -m pytest tests
```
