# Сверка первой даты SalesVisor с приёмкой ПДО (30.09.2026)

Разовый разбор по просьбе РП: сравнить первую дату SalesVisor (первая декада светофора) с якорем «первое появление
позиции в отчёте ПДО по принятым заказам» (метод пилота VOLS-Zakazy). Результат — Excel в папке
«Внедрение ИИ\40_Аналитика и отчёты\42_Записки и разборы\SalesVisor — сверка первой даты с приёмкой ПДО (30.09.2026).xlsx».

Данные в git не кладутся: снимки ПДО — `SalesVisor\data\приёмка\<месяц>\Отчет по принятым заказам …xlsx`,
выгрузки 30.09 — в Downloads (пути в `diff_run.py`).

Порядок (из этой папки, Python с зависимостями SalesVisor):

1. `python diff_run.py C:/Users/ia.fedoseev/Desktop/SalesVisor rel.json` — база SalesVisor на выгрузках (diff_rel.json.db).
2. `python priemka/pr_parse.py` — все снимки ПДО → priemka/rows.pkl (дубли «!…» и «— копия» отбрасываются).
3. `python priemka/pr_compare.py` — якорь, долг, выпуск к сроку по позициям → priemka/cmp.pkl, cmp.txt.
4. `python priemka/pr_excel.py "<путь к xlsx>"` — отчёт.

Главный вывод 30.09: где есть предварительные снимки («в декаду … ver.N»), первая декада светофора совпадает с якорем
в 91 %; за июль–сентябрь в папке только «и факт в декаду», якорь там — уже принятая декада после переносов.
