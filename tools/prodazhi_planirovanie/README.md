# Продажи ↔ планирование: скрипты разбора (с 01.10.2026)

Разбор связей между продажами, размещением, планированием ПДО и исполнением заказов — основа будущего
инструмента в SalesVisor. Выводы и описание — «Внедрение ИИ\40_Аналитика и отчёты\42_Записки и разборы\
Продажи и планирование\» (MD по областям процесса). Данных и секретов здесь нет.

Где данные (на диске, не в git):
- снимки ПДО «Отчёт по принятым заказам …» — `SalesVisor\data\приёмка\` (папка ПДО) и `SalesVisor\data\у2\{2025,2026}`
  (вложения задач «ВАЖНЫЕ НОВОСТИ У2», вместе с «Отчётами по материалам (Z0+Z4)» 2026);
- результаты разбора (pickle) и справочники — `Внедрение ИИ\70_Сырьё и выгрузки\Продажи и планирование (с 01.10.2026)\`;
- реестр просьб У2 — `Downloads\Комментарии к портфелю заказов.xlsx`; ТУ — `Desktop\ТУ\`.

Доступ к Битриксу — только чтение через `CRM-проект\скрипты\bx.py` (вебхук берётся из конфига, в скрипты не попадает).

| Скрипт | Что делает |
|---|---|
| task_read.py, att_dl.py | задача и её комментарии; скачивание вложений (виды: plan, fact, other, segs, mat2026, matsample) |
| links.py, roles.py, corpus.py | номера заказов и ссылки в комментариях; роли авторов по подразделениям; корпус для разметки |
| chats_list.py, chats_fetch.py, chat_corpus.py | список диалогов, сообщения рабочих чатов с 01.2025, корпус «чат × день» (роли вместо ФИО) |
| pr_parse.py | все снимки ПДО → строки по отрезкам (2025 — лист «исх данные», 2026 — первый лист) |
| pr_hier.py | иерархия продукции SAP из «портфеля» ПДО |
| brand.py | марка кабеля из наименования SAP → группа, назначение, броня (каталоги incab.ru, okabel.ru, incabspecialty.ru, ТУ) |
| pr_compare.py | первая дата (якорь первого снимка ПДО) против светофора и SalesVisor |
| pr_process.py, pr_esc.py | события комментариев ↔ решения ПДО по декадам; эскалации против базы |
| pr_requests.py, pr_crit.py | реестр просьб У2 → решение ПДО и исход; критичная дата против первого снимка |
| pr_deficit.py, pr_def_an.py, pr_def2.py | ежедневные отчёты по материалам → история дефицита по позиции, исход к первой дате |
| pr_groups.py | решения ПДО и итог декад по группам РП (грунт — отдельно сталь и стеклопластик) |
| pr_book.py | книга Excel «Продажи и планирование — связи и закономерности» |

Порядок пересчёта: pr_parse → pr_hier → (diff_run из tools/sverka_pdo) → pr_compare → pr_process → pr_requests →
pr_deficit → pr_def_an → pr_groups → pr_book. Пути в скриптах указывают на рабочую папку сессии — при переносе
поправить `HERE`/`SP`.
